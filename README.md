# 190 SL — Анатомія легенди

Інтерактивний односторінковий 3D-сайт про Mercedes-Benz 190 SL (1955–1963). Концепт для портфоліо.

- Машина реагує на курсор: повертається за ним, передні колеса підрулюють.
- Під час скролу авто розбирається на деталі: кузовні панелі, салон, двигун M121 з анімованими поршнями (4 такти), колеса з гальмами.
- Вибір кольору кузова з плавним перефарбуванням.
- Адаптивна якість рендера: сайт сам знижує роздільну здатність на слабких пристроях.

**Стек:** Three.js · GSAP + ScrollTrigger + SplitText · Lenis · чистий HTML/CSS/JS без збірки.

## Запуск локально

Будь-який статичний сервер з кореня репозиторію, наприклад:

```bash
npx serve .
```

або `pwsh tools/serve.ps1` (Windows, без Node) → http://localhost:5173

## Структура

| Шлях | Що там |
|---|---|
| `index.html`, `css/style.css` | розмітка й стилі |
| `js/main.js` | сцени скролу (`SCENES`), мітки, UI |
| `js/scene.js` | 3D-сцена, світло, матеріали, розбір авто |
| `js/engine.js` | процедурний двигун M121 |
| `js/interior.js` | процедурний салон |
| `js/wheel.js` | колеса (шина, диск, гальма) |
| `assets/` | стиснута модель (`car.bin`, `wheel.bin`) і текстури |
| `dev/` | інструменти, що з вихідних OBJ генерують `assets/` (самі вихідні файли не в репозиторії) |
